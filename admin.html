Chave de publicação

nenhuma chave cadastrada

A chave permite que as ferramentas enviem as alterações direto ao repositório, sem baixar e reenviar arquivos à mão. Ela fica guardada somente neste navegador e nunca é gravada em nenhum arquivo do projeto.

Quem está publicando (obrigatório):

Se você recebeu a chave de alguém do GT: basta colar no campo acima e clicar em Testar chave. Não é preciso ter conta no GitHub.

Se é você quem cria a chave: no GitHub, clique na sua foto no canto superior direito e siga por Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em Repository access escolha Only select repositories e marque guiailustrado. Em Permissions, marque Contents: Read and write. Guarde a chave no momento em que ela aparecer: o GitHub não mostra de novo.

Cuidados. A chave é como uma senha: não coloque em e-mail aberto, em documento compartilhado nem dentro de nenhum arquivo do projeto — se ela for parar no repositório, o GitHub a cancela sozinho. Em computador de uso comum, clique em Remover chave ao terminar.

Conferência de imagens

Compara o produtos.csv com os arquivos da pasta imagens e aponta materiais sem imagem, arquivos sem material correspondente e nomes fora do padrão.

/ /

Somente leitura de dados públicos, nenhuma senha é pedida. O repositório precisa ser público. Esta é a forma mais completa de conferência, porque o GitHub informa todos os arquivos da pasta, o que permite descobrir também as imagens que sobraram. A configuração fica salva neste navegador e é a mesma usada pela ferramenta de preparar imagens.

Como publicar uma atualização

  1. Faça as alterações no Editor do catálogo, ou trate as fotos em Preparar imagens.
  2. Confira a lista do que será gravado e desfaça o que não era para estar ali.
  3. Clique em Publicar. Os arquivos vão direto ao repositório, e só os que mudaram.
  4. O site republica sozinho em cerca de um minuto. Confira no endereço público antes de avisar a rede.

Publicar exige a chave cadastrada acima. Sem ela, ou se a rede bloquear o GitHub, o botão de baixar o pacote .zip continua em todas as ferramentas e leva ao mesmo resultado, enviando os arquivos à mão.
