Como publicar uma atualização

  1. Faça as alterações no Editor do catálogo e baixe o pacote .zip.
  2. Descompacte. As pastas de dentro são as mesmas do repositório.
  3. Envie produtos.csv para a raiz e editor-catalogo/historico.md para a pasta do editor.
  4. Para fotos novas, use Preparar imagens e envie os arquivos para a pasta imagens.
  5. O site republica sozinho em cerca de um minuto. Confira no endereço público antes de avisar a rede.
