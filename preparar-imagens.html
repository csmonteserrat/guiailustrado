Preparar imagens do catálogo

Envie a foto do jeito que estiver, vincule ao material e a ferramenta salva já no padrão do catálogo: 800x800, quadrada, fundo branco e nome do código. Tudo acontece dentro deste computador, nenhuma imagem é enviada para a internet.

1. Carregar a lista de materiais

Procurando o arquivo produtos.csv...

Não encontrei o produtos.csv automaticamente. Isso acontece quando a página é aberta direto do disco. Escolha o arquivo abaixo.

2. Situação das fotos

ainda não verificado
Com o repositório preenchido, a ferramenta consulta o GitHub e mostra quais materiais já receberam foto, inclusive as enviadas por outras pessoas. É apenas leitura de dados públicos, nenhuma senha é pedida.

3. Enviar as fotos

Arraste as fotos para cá Pode ser qualquer nome de arquivo. Aceita JPG, PNG e WEBP, várias de uma vez.

Como funciona

  1. A ferramenta lê o produtos.csv e sabe quais materiais ainda estão sem foto.
  2. Você arrasta as fotos com qualquer nome. Se o nome já contiver o código, o vínculo é feito sozinho.
  3. Para as demais, clique em vincular e busque o material pelo nome, pelo código ou pela família.
  4. Clique em Publicar as fotos no site. Elas vão direto para a pasta imagens do repositório, já nomeadas pelo código, e o site republica sozinho.
  5. Se preferir enviar à mão, ou se a chave de publicação não estiver cadastrada, use Baixar as fotos vinculadas: o pacote sai com os arquivos já nomeados, prontos para a pasta imagens.
  6. Publicadas de um jeito ou de outro, elas aparecem como concluídas para todos que abrirem esta página.
